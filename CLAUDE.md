- **CI/CD:** GitHub Actions
- **Hosting:** GitHub Pages

## Development Workflow

### CI/CD Pipeline

The GitHub Actions workflow (`.github/workflows/labs.yml`) triggers on:
- Push to: `samples/images/**`, `pipeline/**`, `schema/**`, `requirements.txt`, or the workflow file itself
- Manual workflow dispatch

Pipeline steps:
1. Checkout repository
2. Setup Python 3.11
3. Install Tesseract OCR with Chinese language support
4. Install Python dependencies from `requirements.txt`
5. Execute: `python pipeline/run.py --in samples/images --out output`
6. Upload output as artifacts

### Running Locally

```bash
# Install system dependencies (Ubuntu/Debian)
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-chi-sim

# Install Python dependencies
pip install -r requirements.txt

# Run the pipeline
python pipeline/run.py --in samples/images --out output
```

## Notes for AI Assistants

1. **Chinese Language Support:** This project specifically requires Chinese character recognition. When implementing OCR functionality, ensure `chi_sim` (Simplified Chinese) language pack is used with Tesseract.

2. **Pipeline Arguments:** The main script expects `--in` for input directory and `--out` for output directory.

3. **GitHub Actions:** Any changes to monitored paths will trigger the CI/CD pipeline automatically.

4. **Output Directory:** The `output/` directory is for generated content and should not contain source files.
